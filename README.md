# SC-DTI: Structure–Sequence Collaborative Learning for Drug–Target Interaction Prediction

SC-DTI is a deep learning framework for drug–target interaction (DTI) prediction. The model integrates drug molecular graphs, protein contact graphs, SMILES sequence semantics, protein sequence representations, fine-grained graph–sequence alignment, and atom–residue interaction modeling to predict whether a given drug–target pair has an interaction.

## Overview

Drug–target interaction prediction is formulated as a binary classification task. Given a drug molecule and a target protein, SC-DTI learns multi-modal representations from both structural and sequential views and outputs the probability of interaction.

The framework mainly contains the following modules:

- **SC-Graph encoding block** for drug molecular graphs and protein contact graphs.
- **Cross-graph interaction view** for atom–residue message passing.
- **ChemBERTa-based SMILES encoder** for drug sequence representation.
- **Hybrid CNN–BiMamba sequence encoder** for local motif and long-range dependency modeling.
- **Fine-grained atom–token alignment module** for graph–sequence semantic fusion.
- **Gated fusion module** for adaptive integration of structural and sequential features.
- **Bidirectional atom–residue interaction module** for final DTI prediction.

## Model Architecture

SC-DTI consists of four major components.

### 1. SC-Graph Encoding Block

The graph encoder takes the drug molecular graph, protein contact graph, and atom–residue bipartite graph as input. It performs message passing from two complementary views:

- **Structural view:** captures intra-graph topological dependencies within the drug graph and protein contact graph.
- **Interaction view:** captures cross-graph contextual information between drug atoms and protein residues.

After multiple graph encoding layers, graph-level representations are obtained for both the drug and the target protein.

### 2. Hybrid Sequence Encoder

For sequence modeling, SC-DTI uses:

- **ChemBERTa** to encode drug SMILES sequences.
- **Amino acid embedding** to encode target protein sequences.
- **1D-CNN** to extract local sequence motifs.
- **Bidirectional Mamba** to capture long-range contextual dependencies.
- **Cross-attention** to exchange sequence-level information between drug and target representations.

### 3. Fine-Grained Graph–Sequence Alignment

To bridge the semantic gap between 2D molecular graphs and 1D SMILES sequences, SC-DTI introduces an atom–token alignment module. Drug atom-level graph features are used as queries, while SMILES token features are used as keys and values. This allows atom representations to incorporate relevant chemical syntax information from SMILES tokens.

### 4. Heterogeneous Feature Fusion and Prediction

SC-DTI applies gated fusion to adaptively balance graph-derived structural features and sequence-derived semantic features. The final prediction module further models bidirectional atom–residue interactions and outputs binary classification logits.

## Data Preparation

Each drug–target pair should contain both graph-level and sequence-level features.

The model expects input data objects with the following fields:

```python
data.mol_x              # atom type indices
data.mol_x_feat         # atom feature matrix
data.mol_edge_index     # molecular graph edge index
data.mol_edge_attr      # bond features

data.prot_node_aa       # protein residue features
data.prot_node_evo      # protein evolutionary features
data.prot_seq_x         # protein sequence indices
data.prot_edge_index    # protein contact graph edge index
data.prot_edge_weight   # protein contact edge weights

data.mol_x_batch        # batch index of atom nodes
data.prot_node_aa_batch # batch index of residue nodes
data.m2p_edge_index     # atom–residue bipartite graph edges

data.smiles             # raw SMILES sequence
# or
data.raw_smiles         # raw SMILES sequence
```

Drug molecular graphs can be constructed from SMILES using RDKit and BRICS. Protein contact graphs can be constructed from predicted residue–residue contact probabilities, such as those generated by ESM-2.


## Model Output

SC-DTI outputs two-dimensional logits:

```python
scores = model(data)  # shape: [batch_size, 2]
```

The two output dimensions correspond to:

```text
class 0: non-interaction
class 1: interaction
```

The positive interaction probability can be obtained by:

```python
prob = torch.softmax(scores, dim=1)[:, 1]
```

For training, the model is compatible with cross-entropy loss or cross-entropy-based losses such as PolyLoss.

Example:

```python
loss = torch.nn.functional.cross_entropy(scores, labels.long())
```

## Evaluation Metrics

The model can be evaluated using commonly used DTI prediction metrics:

- Accuracy
- AUC
- AUPR
- F1-score
- Precision
- Recall

For binary logits, the positive class probability should be computed using softmax before calculating probability-based metrics:

```python
y_score = torch.softmax(logits, dim=1)[:, 1]
```

For threshold-based metrics such as F1-score, the default threshold is usually 0.5:

```python
y_pred = (y_score >= 0.5).astype(int)
```

In cross-dataset validation, threshold calibration may be required because the optimal decision threshold can shift across datasets.
